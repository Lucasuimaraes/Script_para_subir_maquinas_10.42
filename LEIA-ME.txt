SUBIR MÁQUINAS DEBIAN 11 — REDE 10.42

INSTALAÇÃO DIRETA PELO GITHUB

1. Abra o Terminal do Linux Mint.
2. Copie e cole este comando completo. Não use sudo:

python3 -c "import urllib.request as u; open('/tmp/ironvox-10.42.sh','wb').write(u.urlopen('https://raw.githubusercontent.com/Lucasuimaraes/Script_para_subir_maquinas_10.42/main/instalar.sh').read())" && (x-terminal-emulator -e bash /tmp/ironvox-10.42.sh || bash /tmp/ironvox-10.42.sh)

O comando baixa o instalador, abre uma nova janela de Terminal e inicia as perguntas. Não precisa extrair arquivos nem procurar a pasta Downloads. Na nova janela aparecerá:

Quantas máquinas deseja configurar? [1 ou 2]:

O instalador solicitará sua senha sudo para instalar dependências. Em seguida, informe a quantidade (1 ou 2), os IPs atuais das máquinas e a senha root quando solicitada. Confirme e reserve os IPs finais no DHCP/inventário antes de prosseguir; a sondagem por ping não garante que estejam livres.

Depois de aplicar a rede, o programa tenta acessar cada máquina pelo IP novo e executa a validação de saúde em modo consulta. O progresso aparece no Terminal. Os relatórios ficam em:

~/Relatorios-validacao-servidor/

O programa não realiza testes intencionais de carga nem envia relatórios ao GitHub.
Ao terminar os testes de saúde, ele abre uma janela de Terminal conectada como root para cada máquina configurada. Para duas máquinas, abre duas janelas.

O projeto é mantido em ~/.local/share/ironvox/Script_para_subir_maquinas_10.42 e as próximas execuções atualizam os arquivos do Git automaticamente.
